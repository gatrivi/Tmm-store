# Leads por anillos — Olivos → afuera

Propósito: locales con **100+ reseñas Google** y **sin web propia** (solo IG/FB/pedix = cuenta como sin web). Perfil Trufi: roti, pizza, empanadas, delivery/WSP.

Ancla: **Olivos** (`-34.5075, -58.4878`). Anillos cada **5 km**.

| Tier | Zona | Radio |
|------|------|-------|
| **T0** | Olivos | 0–5 km |
| **T1** | Vicente López (partido) | 5–10 km |
| **T2** | Florida / La Lucila / Villa Adelina | 10–15 km |
| **T3** | Munro / Martínez / San Isidro borde | 15–20 km |

**Fit:** A = ideal (pizza/roti/empanadas) · B = posible (parrilla/cantina) · C = bajo (sushi/resto fino)

## Rutina semanal (30 min/día)

```mermaid
flowchart LR
  lun[Lun T0 walk-in x2] --> mar[Mar T0 call x3]
  mar --> mie[Mié T1 WSP x3]
  mie --> jue[Jue T1 walk-in x2]
  jue --> vie[Vie T2 call x3]
  vie --> sab[Sáb demo prep]
```

| Día | Acción | Meta |
|-----|--------|------|
| **Lun** | Caminar T0 · 2 locales · peak 11:30 o 19:30 | 2 conversaciones |
| **Mar** | Llamar T0 · filas 1–3 del tier | 3 llamadas → 1 demo |
| **Mié** | WSP T1 · pitch 30s + link demo | 3 mensajes |
| **Jue** | Walk-in T1 · La Malvada / Esquina 7 | 2 visitas |
| **Vie** | Llamar T2 · VÍCTOR + scan nuevos | 3 llamadas |
| **Sáb** | Demo 10 min si agendó · [`demo.md`](./demo.md) | 1 demo |
| **Dom** | Off · anotar métricas | — |

### Por contacto (2 min)

1. Maps: confirmar reseñas + que no tengan web nueva.
2. Pitch: [`sales-playbook-zn.md`](./sales-playbook-zn.md) (30 s).
3. Status en tabla: `—` → `WSP` → `demo` → `piloto` → `pago` / `no`.

### Orden de ataque (Trufi fit × volumen)

1. Morelia → San Antonio → Dale Vicente → Rincón del Bajo → Croxi  
2. VÍCTOR (T2 pero A++ y clásico roti)  
3. Biblos / Esquina 7  
4. Parrilla Nelly / La Farola / La Malvada (volumen alto, perfil menos ideal)
