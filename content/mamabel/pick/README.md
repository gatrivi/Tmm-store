# Elegí fotos — Mamá Mabel

Abrí esta carpeta en el Explorador y mirá las miniaturas.

Decime por **código de archivo** (ej. `A03`, `C01`, `B02`) qué va en:

1. **Hero** (portada)
2. **Oficio** (retrato + 4–6 de apoyo)
3. **Trabajos / portfolio** (8–14)
4. **Cursos** (flyer / aula — cuidado: ya traen texto)
5. **Descartar**
